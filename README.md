# Needora — Hyperlocal Discovery & Multi-Role Commerce Platform

A production-grade, full-stack Next.js web application built with TypeScript, Tailwind CSS, and Lucide React. Designed for authentic local Indian commerce with 100% human-designed aesthetics (zero robotic/AI-styled icons or fake placeholder data).

## 👥 Three Separated Roles

- **Customer Marketplace (`/`)**: Discover local services, pick dates & time slots, calculate GST/delivery fees, checkout via UPI/Card/COD, use Vernacular Voice Search (Telugu, Hindi, English).
- **Merchant Workspace (`/merchant`)**: Manage store profile, live order fulfilment queue (Accept -> Prepare -> Dispatch -> Deliver), catalogue & pricing, promotional offers.
- **Admin Trust & Safety Suite (`/admin`)**: Merchant verification queue, GSTIN/FSSAI credential inspection, geographic proximity duplicate detector, customer complaints log, user directory.
